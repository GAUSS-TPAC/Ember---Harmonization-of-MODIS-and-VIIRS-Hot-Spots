# Ember---Harmonization-of-MODIS-and-VIIRS-Hot-Spots
Harmonized burning-activity calendar built from 25+ years of NASA FIRMS active-fire hotspots. Calibrates MODIS (2000–) onto VIIRS (2012–) so sensor changes no longer bias trends, then serves an interactive web app: draw an area, explore seasonal patterns, anomalies vs. historical median, and export CSV. NASA Space Apps 2026.
